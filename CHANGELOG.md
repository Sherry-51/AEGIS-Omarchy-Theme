# Changelog

All notable changes to the **AEGIS — Deep Space Command Center** theme will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-01

### Added
- **Core Visual Identity:** Deep space command center theme for Omarchy Linux 4.x on Arch Linux / Hyprland / Quickshell.
- **Palette Architecture:** WCAG AAA compliant 15.08:1 contrast palette in `colors.toml` featuring `#080B14` primary background, `#05070D` absolute dark background, `#74D7E8` ice cyan active accent, `#3E6FA8` mission blue, `#8876B8` cosmic purple, and full ANSI 16-color specification.
- **System Telemetry:** Custom high-precision `btop.theme` telemetry monitoring dashboard.
- **Curated Wallpaper Collection:** Exactly 16 ultra-high quality 2560×1440 wallpapers spanning NASA scientific observation, planetary limbs, lunar regolith, Apollo Hasselblad photography, and original AEGIS telemetry vector art.
- **Desktop Shell Integration:** Native Omarchy Quickshell styling covering top status bar, application launcher, notifications, popups, lock screen, and window borders.
- **Terminal Styling:** Seamless Foot and Alacritty configuration with ANSI color mapping, visible cursor, and distinct selection styling.
- **Neovim Console Integration:** Full syntax highlighting and LSP diagnostics support via `aether.nvim` and LazyVim hot-reloading.
- **Browser & Utility Styling:** Chromium theme color policy and `Yaru-blue-dark` icon theme pairing.
- **Comprehensive Documentation:** Full `README.md` and `SOURCES.md` documenting every asset and its license.
